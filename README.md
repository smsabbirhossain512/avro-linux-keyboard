# Avro Phonetic for Linux (Rust Edition v2.0)

Linux (Ubuntu, Fedora, Debian, Linux Mint, Arch)-এর জন্য সম্পূর্ণ **Rust** ল্যাঙ্গুয়েজে তৈরি একটি অতি-দ্রুতগতির (Ultra-Fast) ও নির্ভরশীলতামুক্ত Avro Phonetic বাংলা কিবোর্ড ইঞ্জিন।

## কেন Rust ভার্সন সেরা?

- **জিরো ল্যাগ ও হাই-স্পিড:** পিওর Rust-এ কম্পাইল করা নেটিভ বাইনারি হওয়ায় টাইপ করার সাথে সাথে চোখের পলকে রেসপন্স করে।
- **কোনো Python কনফ্লিক্ট নেই:** সিস্টেমের Python লাইব্রেরি আপডেট হলেও কিবোর্ড নষ্ট হওয়ার কোনো ভয় নেই।
- **ইউনিভার্সাল সাপোর্ট:** Ubuntu (24.04/26.04 Wayland সহ), Fedora, Linux Mint, Debian এবং Arch-সহ সব ডিস্ট্রিবিউশনে এক কমান্ডেই ইনস্টল হয়।

---

## কীভাবে ইনস্টল করবেন?

### পদ্ধতি ১: এক কমান্ডে অটোমেটিক ইনস্টল (সবচেয়ে সহজ)
যেকোনো লিনাক্স ডিস্ট্রিবিউশনে (Ubuntu, Fedora, Mint, Debian, Arch) টার্মিনাল খুলে নিচের কমান্ডটি পেস্ট করে **Enter** চাপুন। এটি প্রয়োজনীয় ডিপেন্ডেন্সি, Rust এবং IBus অটোমেটিক সেটআপ করে নেবে:

```bash
rm -rf /tmp/avro-linux-keyboard && git clone https://github.com/smsabbirhossain512/avro-linux-keyboard.git /tmp/avro-linux-keyboard && cd /tmp/avro-linux-keyboard && chmod +x install.sh && ./install.sh

```

### পদ্ধতি ২: ZIP ডাউনলোড করে ম্যানুয়াল ইনস্টল
১. পেজের উপরে সবুজ **<> Code** বাটনে ক্লিক করে **Download ZIP** নামিয়ে Extract করুন।
২. ফোল্ডারের ভেতরে টার্মিনাল খুলে নিচের কমান্ডটি চালান:
```bash
chmod +x install.sh && ./install.sh
```

### ইনস্টল শেষ হওয়ার পর করণীয়:
- একবার **Log Out** করে **Log In** করুন (যাতে Wayland/X11 সেশনে নতুন কিবোর্ড লোড হয়)।
- কিবোর্ডে **`Super + Space`** (Windows কী + Spacebar) চেপে English ও **Avro Phonetic (Rust Ultra-Fast)**-এর মধ্যে সুইচ করে বাংলায় লিখুন!

*(বিঃদ্রঃ যদি আপনার ডিস্ট্রোতে `git` ইনস্টল না থাকে, তবে প্রথম কমান্ডটির আগে `sudo apt install -y git` বা `sudo dnf install -y git` চালিয়ে নিন।)*

## সম্পূর্ণ বাংলা টাইপিং Key List

### ১. স্বরবর্ণ ও কার-চিহ্ন (Vowels & Kar)

- **স্বরবর্ণ:** `o` = অ, `a` = আ, `i` = ই, `I` / `ee` = ঈ, `u` = উ, `U` / `oo` = ঊ, `rri` = ঋ, `e` = এ, `OI` = ঐ, `O` = ও, `OU` = ঔ
- **কার-চিহ্ন:** `ka` = কা, `ki` = কি, `kI` / `kee` = কী, `ku` = কু, `kU` / `koo` = কূ, `krri` = কৃ, `ke` = কে, `kOI` = কৈ, `kO` = কো, `kOU` = কৌ

### ২. ব্যঞ্জনবর্ণ (Consonants)

- `k` / `q` / `Q` = ক, `kh` = খ, `g` = গ, `gh` = ঘ, `Ng` = ঙ, `ng` = ং
- `c` = চ, `ch` = ছ, `j` = জ, `jh` = ঝ, `NG` = ঞ
- `T` = ট, `Th` = ঠ, `D` = ড, `Dh` = ঢ, `N` = ণ
- `t` = ত, `th` = থ, `d` = দ, `dh` = ধ, `n` = ন
- `p` = প, `ph` / `f` = ফ, `b` = ব, `bh` / `v` = ভ, `m` = ম
- `z` = য, `y` / `Y` = য়, `r` = র, `l` = ল, `sh` = শ, `S` = ষ, `s` = স, `h` = হ, `R` = ড়, `Rh` = ঢ়
- `w` / `W` (শুরুতে) = ও, `w` / `W` (ব্যঞ্জনের পরে) = ্ব (ব-ফলা), `t``` = ৎ, `H` = ঃ, `^` = ঁ, `,,` = হসন্ত (্)
- **দাঁড়ি ও ডট:** একবার `.` = **।** (দাঁড়ি), দুবার `..` = **.** (ডট), `0-9` = ০-৯

### ৩. যুক্তবর্ণ ও বিশেষ শর্টকাট (Conjuncts)

- **ফলা ও রেফ:** `ky` = ক্য (য-ফলা), `kr` = ক্র (র-ফলা), `kw` = ক্ব (ব-ফলা), `rk` = র্ক (রেফ)
- **বিশেষ যুক্তবর্ণ:** `ksh` / `kkh` = ক্ষ, `jng` / `gg` = জ্ঞ, `x` = ক্স, `hm` = হ্ম, `nch` = ঞ্চ, `nj` = ঞ্জ
- **সাধারণ যুক্তবর্ণ:** `ngk` = ঙ্ক, `ngg` = ঙ্গ, `tt` = ত্ত, `tth` = ত্থ, `tn` = ত্ন, `tm` = ত্ম, `tw` = ত্ব, `dd` = দ্দ, `ddh` = দ্ধ, `dw` = দ্ব, `dm` = দ্ম, `nt` = ন্ত, `nth` = ন্থ, `nd` = ন্দ, `ndh` = ন্ধ, `nn` = ন্ন, `mp` = ম্প, `mb` = ম্ব, `mbh` = ম্ভ, `shc` = শ্চ, `shw` = শ্ব, `shr` = শ্র, `ShT` = ষ্ট, `ShTh` = ষ্ঠ, `ShN` = ষ্ণ, `sk` = স্ক, `st` = স্ত, `str` = স্ত্র, `sth` = স্থ, `sn` = স্ন, `sp` = স্প, `sw` = স্ব, `sm` = স্ম, `tr` = ত্র, `bd` = ব্দ, `kt` = ক্ত, `gn` = গ্ন

## আনইনস্টল করার নিয়ম (Uninstall)
যেকোনো সময় কিবোর্ডটি রিমুভ করতে চাইলে টার্মিনালে নিচের কমান্ডটি চালান:
```bash
sudo rm -f /usr/local/bin/avro-rust /usr/share/ibus/component/avro-rust.xml && sudo ibus write-cache && ibus restart
```
